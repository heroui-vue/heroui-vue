# 介绍

HeroUI Vue是一个基于 [@heroui/theme](https://npmx.dev/package/@heroui/theme) 的 Vue3 组件库，以 [HeroUI v2](https://v2.heroui.com) 为目标，提供了一套现代化的、类型化的组件。

HeroUI Vue是由个人发起的兴趣项目，和HeroUI Inc.无关

## 组件

HeroUI Vue还处于早期阶段，初始目标是迁移HeroUI所有的组件，以保证最小可用性。对于迁移的Vue组件，按照HeroUI组件文档中的示例使用，可以正确渲染并保持一致的效果，则认为该组件满足最小可用性。

组件开发的优先级依据它们的属性来决定，通常，纯视觉组件会优先实现，因为它们足够简单。目前，组件的属性划分为以下几项，优先级从高到低：

- 纯视觉组件
- 表单组件
- 高度交互组件
- 多层级组件

除此以外，文档示例的复杂度也会影响优先级。比如，示例中包含了其他复杂的组件，这可能会导致优先级延后。

在开发阶段，组件以独立包的形式存在，因此它们可以单独打包和发布，站在用户的角度，包可以按需使用。关于更多，请参考[快速开始](/zh/guide/quick-start)以及对应组件的文档。

## 文档

组件的示例会和HeroUI文档保持一致，因为这对组件的验证非常重要。但是更详细的部分，比如Props、插槽、属性，文档的内容会出现偏差，一部分原因是Vue和React的特性差异，但最主要的是，早期开发的权衡。精力和时间是有限的，它们应该集中到组件本身的开发。目前大部分组件文档的编写由AI完成，也许是使用的模型能力不够，看起来有不少问题。因此，关于组件文档，请参考组件的类型信息。

在未来，会通过迁移注释，然后使用工具来生成文档。这样既可以提高和HeroUI的一致性和准确性，还能大幅减少开发成本。
